# Bookstore Management System

A beginner-friendly C# console application for managing a simple bookstore.

## Features

* Add new books
* Delete books by name
* View all books
* Count books and calculate total price
* Search for books by name
* Prevent duplicate books with the same title and author
* Validate book prices
* Support multiple books with the same title but different authors

## Technologies

* C#
* .NET
* Console Application
* `List<T>`
* Basic Object-Oriented Programming concepts

## How to Run

1. Clone or download the repository.
2. Open the project in Visual Studio or your preferred C# IDE.
3. Build and run the project.
4. Follow the instructions in the console menu.

## Menu

```text
1. Add a new book
2. Delete book with name
3. View all books
4. All books count
5. Search by book name
0. Exit
```

## About

This project was created as a beginner C# practice project to improve programming fundamentals, working with lists, loops, conditions, methods, input validation, and console applications.
